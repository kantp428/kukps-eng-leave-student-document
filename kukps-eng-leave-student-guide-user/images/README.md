# มาตรฐานภาพคู่มือ

- ภาพใช้งานทั้งหมดอยู่ในโฟลเดอร์นี้และใช้ PNG จริง ไม่ใช่เพียงเปลี่ยนนามสกุล
- ชื่อไฟล์ใช้ภาษาอังกฤษตัวเล็กคั่นด้วยขีดกลาง เช่น `student-home.png`
- ภาพหลายส่วนต่อท้ายด้วยลำดับ เช่น `student-report-1.png`, `student-report-2.png`
- ภาพรุ่นก่อนที่ชื่อชนกับภาพใหม่ใช้ท้ายชื่อ `-legacy.png` และคู่มือยังอ้างอิงรุ่นเดิมเมื่อภาพใหม่มีข้อมูลไม่ครบ
- ภาพต้นฉบับเก็บใน `originals/` เพื่อย้อนกลับได้ ไม่ใช้เป็นโฟลเดอร์ภาพหลัก
- `manifest.json` ระบุภาพใหม่กับ URL และ `rename-map.json` บันทึกชื่อก่อนและหลังปรับ
- ดูรายการภาพและสถานะล่าสุดใน `../capture.md`
