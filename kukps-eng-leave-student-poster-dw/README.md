# โปสเตอร์คลังข้อมูลการลานิสิต

เน้น warehouse: เส้นทางข้อมูล ETL, grain สองระดับ, การนับไม่ซ้ำ และคำถามของผู้ใช้ 6 บทบาท ใช้ภาษาง่ายแทนบทคัดย่อทางวิชาการ รายชื่อผู้จัดทำ 4 คนพร้อมรหัสนิสิต ไม่มีชื่ออาจารย์ที่ปรึกษา

- คอมไพล์: `scripts/build.ps1`
- PDF ล่าสุด: `poster-a4.pdf` (A4 ย่อจากผัง A2)
- แผนภาพวาดด้วย TikZ ไม่จับหน้าจอใหม่
- เนื้อหาเดิมสำรองใน `work/before-warehouse-poster/main.tex`
- หน้าเว็บรายงานปัจจุบันใช้ข้อมูลจำลอง จึงไม่อ้างผลใช้งานจริง

ภาพและเนื้อหาเก่าที่ main ไม่เรียกใช้ไม่ใช่ส่วนของโปสเตอร์ฉบับนี้ ไฟล์ poster-a2.pdf ที่คัดลอกมาเดิมไม่ได้ใช้เป็นฉบับล่าสุด
